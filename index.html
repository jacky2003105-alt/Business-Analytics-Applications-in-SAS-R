商業分析：R｜課程筆記

這是「商業分析：R」第 1～8 章的課程筆記。內容以老師的網頁版講義為骨架，從完全沒寫過 R 的角度重新寫：每個函數都說明「它在做什麼、引數是什麼意思、輸出要怎麼看」。所有程式碼都實際跑過，灰底是程式，下方以 ## 開頭的是 R 的輸出，圖也是 R 跑出來的。

每一節最後有一組 Concept Check，題型照期末考考古題的四種出法：英文選擇題、填空（填函數名稱）、簡答（用自己的話解釋）、寫程式。題目是自編的練習，不是老師出的題目；考古題真的出過的觀念，正文會用橘色的「考古題出過」框標出來。

章節

第 1 章　R 基礎與資料處理

向量、矩陣、串列、因子、資料框；讀檔、檢視資料、處理缺失值 NA。

第 2 章　資料轉換與整理：tidyverse

管線 %>%、dplyr 六個動詞、tidyr 重塑資料、join 合併資料表。

第 3 章　自訂函數與流程控制

自訂函數、預設引數、print／cat／message／warning／stop、if、for、while、apply 家族。

第 4 章　機率分配

d／p／q／r 四個前綴；二項分配、常態分配，用模擬對照理論。

第 5 章　視覺化與探索式資料分析

EDA 依變數選圖、R 內建繪圖、ggplot2 圖層、hjust／vjust、資料轉換。

第 6 章　迴歸分析

lm()、summary 怎麼讀、類別變數與交互作用、殘差診斷、AIC 與逐步迴歸。

第 7 章　廣義線性模型 GLM

glm() 的分配與連結函數；邏輯斯迴歸、勝算比、混淆矩陣、ROC；Poisson 迴歸。

第 8 章　訓練集、測試集與重抽樣

訓練集／測試集、K 折交叉驗證、LOOCV、bootstrap。

環境設定

先安裝 R 與 RStudio，再在 RStudio 的 Console 執行下面這段（只要做一次）：

R
install.packages(c(
  "tidyverse",     # 第 2、4、5 章：dplyr、tidyr、ggplot2
  "nycflights13",  # 第 2 章航班資料
  "corrplot",      # 第 5 章相關圖
  "broom", "car", "MASS", "foreign",   # 第 6 章
  "AER", "pROC", "ISLR", "ISwR",       # 第 7 章
  "boot"                               # 第 8 章
))

每次開新的 R 工作階段，要用到的套件都要再 library() 一次。install.packages() 是「下載安裝」，library() 是「這次要用」——兩者常被搞混。

讀檔前要讓 R 找得到檔案：把下面的資料檔放到同一個資料夾，在 RStudio 選 Session → Set Working Directory → Choose Directory 指到那個資料夾（等同 setwd()）。

期末考題型

考古題（Moodle 線上測驗）分四大部分：

  • 選擇題（每題 3 分）：英文題幹，看一段 R 程式碼判斷結果，例如「哪一行會取出矩陣的第二欄」「哪一個會出現 Error」。
  • 簡答題（每題 5 分）：英文問答，例如 EDA 的重要性、監督式與非監督式學習的比較、%>% 的用途並舉例。
  • 填充題（每題 5 分）：填函數名稱或專有名詞，例如讀 CSV 的函數、做 ANOVA 的函數、配適邏輯斯迴歸的函數、檢查缺失值的函數。
  • 寫程式（10～11 分）：貼上 R 程式碼，例如 filter 與 mutate、回傳 list 的函數、有預設引數的函數。
