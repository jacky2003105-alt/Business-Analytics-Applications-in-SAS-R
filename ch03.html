同一段程式要重複用好幾次、或邏輯開始變複雜時，就該把它包成函數（function），並用流程控制（control flow）決定程式要走哪條路、要重複幾次。這一章學會：自己寫函數、設定預設引數、回傳多個結果；用 print()、cat()、message()、warning()、stop() 輸出訊息；用 if、ifelse、switch 做判斷；用 for、while、repeat 做迴圈；最後用 apply 家族取代迴圈。

期末考的寫程式題有兩題就出在這一章：寫一個回傳 list 的函數、寫一個有預設引數的函數。

3.1自訂函數

函數的三個部分

R
函數名稱 <- function(引數1, 引數2) {
  # 運算的程式碼
  return(結果)
}
  1. 輸入：function() 括號裡的引數（argument）。
  2. 運算：大括號 { } 裡的程式。
  3. 輸出：return() 送回的結果。

先從最簡單的開始，計算 BMI：

R
bmi_cal <- function(height, weight) {
  height <- height / 100        # 公分換成公尺
  bmi <- weight / height^2
  return(bmi)
}
bmi_cal(155, 52)

## [1] 21.64
R
bmi_cal(weight = 70, height = 180)   # 用名稱指定，順序可以不同

## [1] 21.6
  • 執行 bmi_cal <- function(...) {...} 這段時，只是定義函數，不會有任何輸出；要呼叫 bmi_cal(155, 52) 才會真的計算。
  • 呼叫時，155 依位置對應到 height、52 對應到 weight。
  • 函數裡建立的 bmi、改過的 height 只存在函數內部（區域變數），函數結束就消失，不會影響外面同名的物件。

動機：避免重複

想對資料框的每一欄做最小–最大標準化 \(\dfrac{x-\min(x)}{\max(x)-\min(x)}\)（把數值縮到 0～1 之間）：

R
set.seed(2026)
df <- data.frame(a = rnorm(10), b = rnorm(10), c = rnorm(10), d = rnorm(10))

一欄一欄寫，程式又長又容易複製貼上出錯：

R
(df$a - min(df$a)) / (max(df$a) - min(df$a))
(df$b - min(df$b)) / (max(df$b) - min(df$a))   # ← 複製時忘記改，bug！

寫成函數，邏輯只寫一次：

R
scalefnc <- function(x) {
  maxmin <- range(x, na.rm = TRUE)    # c(最小值, 最大值)
  return((x - maxmin[1]) / (maxmin[2] - maxmin[1]))
}
round(scalefnc(df$a), 3)

##  [1] 1.000 0.473 0.874 0.801 0.609 0.000 0.586 0.493 0.866 0.673
R
round(scalefnc(c(10, 20, 15, NA)), 3)

## [1] 0.0 1.0 0.5  NA
  • range() 一次回傳長度 2 的向量，maxmin[1] 是最小、maxmin[2] 是最大。
  • na.rm = TRUE 讓有 NA 的資料也能算；NA 的位置結果仍是 NA。

return() 可以省略

函數會自動回傳最後一行的結果，所以這兩個函數一樣：

R
sq1 <- function(x) { return(x^2) }
sq2 <- function(x) { x^2 }
c(sq1(4), sq2(4))

## [1] 16 16

return() 的真正用途是「提早結束」：

R
safe_sqrt <- function(x) {
  if (x < 0) return(NA)    # 負數直接回傳 NA，後面不執行
  sqrt(x)
}
safe_sqrt(9); safe_sqrt(-1)

## [1] 3
## [1] NA

Q1

選擇｜易定義與呼叫

After running the code below, what is printed in the console?

R
add_tax <- function(price) {
  price * 1.05
}
  1. (A)Nothing; the function is only defined
  2. (B)An error, because no argument was given
  3. (C)The value 1.05, since price is missing
  4. (D)The full source code of the function

中文題意

執行這段程式後，Console 會印出什麼？

答案 (A)

Nothing; the function is only defined

解析

這段只是把函數存進 add_tax 這個物件，沒有呼叫它，所以什麼都不會印。要寫 add_tax(100) 才會得到 105。

Q2

選擇｜中區域變數

What is the value of x after running the following code?

R
x <- 10
f <- function(x) {
  x <- x * 2
  x
}
y <- f(3)
  1. (A)6
  2. (B)20
  3. (C)10
  4. (D)3

中文題意

執行後，x 的值是多少？

答案 (C)10

解析

函數內的 x 是區域變數，f(3) 在函數內把 3 變成 6 並回傳給 y，但不會改到外面的 x，所以 x 仍是 10，y 是 6。

寫程式｜易攝氏轉華氏

Write a function c_to_f that converts a temperature in Celsius to Fahrenheit using \(F = C \times 9/5 + 32\), and test it with c(0, 25, 100).

中文題意

寫一個攝氏轉華氏的函數，用 0、25、100 測試。

答案
R
c_to_f <- function(celsius) {

}

## [1]  32  77 212

解析

因為 R 的運算是向量化的，函數不需要迴圈就能一次處理整個向量。

Q4

選擇｜中沒有 return 時的回傳值

What does f <- function(x) { y <- x * 2; y + 1 } return for f(3)?

  1. (A)6, the value assigned to y
  2. (B)7, the last expression evaluated
  3. (C)NULL, since there is no return()
  4. (D)An error, because return() is missing

中文題意

沒有寫 return() 時，f(3) 回傳什麼？

答案 (B)

7, the last expression evaluated

解析

R 的函數會回傳最後一個被計算的運算式的值，這裡是 y + 1 = 7。return() 主要用在需要提早離開函數的時候。

3.2預設引數與回傳多個結果

預設引數

在 function() 裡寫 引數 = 值，呼叫時沒給這個引數就用預設值：

R
greet <- function(name = "Guest") {
  paste0("Hello, ", name, "!")
}
greet()          # 沒給 name，用預設的 "Guest"

## [1] "Hello, Guest!"
R
greet("Amy")     # 有給就用給的

## [1] "Hello, Amy!"
  • paste0() 把幾段文字黏在一起，中間不加空格；paste() 預設中間加一個空格，可以用 sep = 改。
R
paste("A", "B", "C")

## [1] "A B C"
R
paste("A", "B", "C", sep = "-")

## [1] "A-B-C"
R
paste0("A", "B", "C")

## [1] "ABC"
R
paste0("Q", 1:3)          # 向量化：一次產生三個字串

## [1] "Q1" "Q2" "Q3"

R 內建函數到處都是預設引數，例如 mean(x, na.rm = FALSE)、round(x, digits = 0)、read.csv(file, header = TRUE)——沒寫的時候就是用這些預設值。

考古題出過寫程式題：有預設引數的函數

考古題：「Function with Default Arguments: a. Define a function named greet that takes a person's name as an input and defaults to "Guest" if no name is provided. b. Extend the function from 2a to also include a greeting message, such as "Hello, [Name]!"」上面的 greet() 就是答案，本節 Concept Check 有完整寫法。

回傳多個結果：用 list 打包

函數只能回傳一個物件。要回傳好幾個結果（例如個數、平均、標準差），就把它們包成一個 list：

R
my.stat <- function(x) {
  x.number <- length(x)
  x.mean   <- mean(x)
  x.sd     <- sd(x)
  list(number = x.number, mean = x.mean, sd = x.sd)
}
res <- my.stat(c(2, 4, 4, 5, 7, 9))
res

## $number
## [1] 6
## 
## $mean
## [1] 5.167
## 
## $sd
## [1] 2.483
R
res$mean       # 用 $ 取出需要的部分

## [1] 5.167

用 c() 也能打包成具名向量，但所有結果會被轉成同一種型別：

R
my.stat2 <- function(x) c(number = length(x), mean = mean(x), sd = sd(x))
my.stat2(c(2, 4, 4, 5, 7, 9))

## number   mean     sd 
##  6.000  5.167  2.483

結果都是數字時 c() 沒問題；只要有文字或長度不同的結果（例如再回傳一個向量），就必須用 list。

考古題出過寫程式題：回傳 list 的函數

考古題：「Function with Multiple Outputs: Create a function named summary_stats that takes a numeric vector and returns a list containing its mean, median, standard deviation, and minimum and maximum values.」寫法和 my.stat() 一樣，見本節 Concept Check。

Q1

寫程式｜中考古題型：summary_stats

Function with Multiple Outputs: Create a function named summary_stats that takes a numeric vector and returns a list containing its mean, median, standard deviation, and minimum and maximum values.

中文題意

建立 summary_stats 函數：輸入數值向量，回傳包含平均、中位數、標準差、最小值、最大值的 list。

答案
R
summary_stats <- function(x) {
  list(mean   = mean(x),
       median = median(x),
       sd     = sd(x),
       min    = min(x),
       max    = max(x))
}
summary_stats(c(3, 8, 1, 9, 4))

## $mean
## [1] 5
## 
## $median
## [1] 4
## 
## $sd
## [1] 3.391
## 
## $min
## [1] 1
## 
## $max
## [1] 9

解析

考古題原題（10 分）。重點：(1) 函數名稱照題目寫；(2) 用 list() 回傳；(3) 每個元素命名，呼叫端才能用 $mean 取用。想更穩健可以在每個函數加 na.rm = TRUE，或加一個引數 na.rm = FALSE 傳進去。

Q2

寫程式｜中考古題型：greet

Function with Default Arguments: a. Define a function named greet that takes a person's name as an input and defaults to "Guest" if no name is provided. b. Extend the function from (a) to also include a greeting message, such as "Hello, [Name]!"

中文題意

(a) 定義 greet，引數 name 預設為 "Guest"；(b) 擴充成輸出 "Hello, [Name]!"。

答案
R
# a.
greet <- function(name = "Guest") {
  return(name)
}
greet()

## [1] "Guest"
R
# b.
greet <- function(name = "Guest") {
  msg <- paste0("Hello, ", name, "!")
  return(msg)
}
greet()

## [1] "Hello, Guest!"
R
greet("Jacky")

## [1] "Hello, Jacky!"

解析

考古題原題（11 分）。(a) 的重點是 name = "Guest" 這個預設值；(b) 用 paste0() 或 paste("Hello,", name) 組字串。也可以用 cat() 直接印出，但用 return() 回傳字串比較好，呼叫端還能拿去用。下一節會說明 print、cat、message 的差別。

易錯提醒

paste("Hello, ", name, "!") 會在每段之間多一個空格，變成 "Hello, Jacky !"。

Q3

選擇｜中為什麼用 list

A function needs to return a numeric mean, a character label and a vector of residuals. Which return value is most appropriate?

  1. (A)c(mean, label, residuals)
  2. (B)data.frame(mean, label, residuals) for any lengths
  3. (C)return(mean); return(label); return(residuals)
  4. (D)list(mean = m, label = lab, residuals = r)

中文題意

函數要回傳一個平均數、一個文字標籤、一個殘差向量，哪種寫法最合適？

答案 (D)list(mean = m, label = lab, residuals = r)

解析

c() 會把全部轉成文字；函數遇到第一個 return() 就結束，後面的 return 不會執行；data.frame 要求各欄等長，平均數只有 1 個、殘差有很多個。只有 list 能裝不同型別、不同長度的東西。

Q4

選擇｜易paste 與 paste0

What is the output of paste("Q", 1:2, sep = "")?

  1. (A)"Q 1" "Q 2"
  2. (B)"Q1Q2"
  3. (C)"Q1" "Q2"
  4. (D)"Q" "1" "2"

中文題意

paste("Q", 1:2, sep = "") 的輸出是什麼？

答案 (C)"Q1" "Q2"

解析

sep = "" 表示中間不加空白，效果等於 paste0()。paste 是向量化的，1:2 有兩個元素，所以產生兩個字串。要合成單一字串 "Q1Q2" 需再加 collapse = ""。

3.3輸出與訊息：print、cat、message、warning、stop

R 有好幾種「讓 Console 出現文字」的方式，用途不同：

函數 用途 程式會不會停
print() 輸出物件的結果（照 R 的格式，帶 [1]、引號） 不會
cat() 格式化輸出：把幾段文字串起來印，可以控制換行 不會
message() 提示訊息（例如「正在讀取資料」） 不會
warning() 警告：有風險，但可以繼續 不會
stop() 錯誤：無法繼續，立刻停止 會

print() 與 cat()

R
x <- "Hello World"
print(x)       # 有 [1] 和引號：這是 R 物件的樣子

## [1] "Hello World"
R
cat(x)         # 沒有 [1]、沒有引號：純文字

## Hello World
R
print(c(1, 2, 3))

## [1] 1 2 3
R
cat(1, 2, 3)   # 用空格隔開

## 1 2 3
R
cat("The mean is", mean(c(2, 4, 9)), "\n")   # 文字和數字可以混著串

## The mean is 5
  • 在 Console 直接打物件名稱，等於自動 print()。但在函數或迴圈裡，物件不會自動印出，要明確寫 print()。
  • cat() 預設以空格分隔各段，用 sep = 可以改：cat("a", "b", sep = "")。
  • cat() 結尾不會自動換行，所以常在最後加 "\n"。

跳脫字元：\n 換行、\t Tab

字串裡的反斜線 \ 開頭的組合代表特殊字元：

寫法 意思
\n newline，換行
\t tab，跳到下一個定位點（對齊用）
\" 字串中的雙引號
\\ 一個反斜線本身
R
for (bloodtype in c("A", "B", "O", "AB")) {
  cat(bloodtype, "\t")          # 每個血型後面接一個 Tab
}

## A 	B 	O 	AB
R
cat("\n")
R
for (bloodtype in c("A", "B", "O", "AB")) {
  cat("my blood type is", bloodtype, "\n")   # 每行印完換行
}

## my blood type is A 
## my blood type is B 
## my blood type is O 
## my blood type is AB
R
cat("Name\tScore\nAmy\t90\nBob\t85\n")       # 用 \t 對齊、\n 換行做出表格

## Name	Score
## Amy	90
## Bob	85
R
print("Name\tScore")                         # print 不解讀跳脫字元，照原樣顯示

## [1] "Name\tScore"

\n、\t 只有在 cat()、message()、writeLines() 這類「輸出文字」的函數中才會真的變成換行和 Tab；print() 顯示的是字串的原始寫法。

message()、warning()、stop()

R
message("Reading data...")                      # 提示

## Reading data...
R
log(-1)                                         # 內建函數發出的警告：產生 NaN

## Warning in log(-1): NaNs produced
## [1] NaN
R
warning("Sample size is small; results may be unstable.")

## Warning: Sample size is small; results may be unstable.
R
stop("Input must be numeric.")                  # 錯誤：程式停在這裡

## Error in eval(expr, envir, enclos): Input must be numeric.

自己寫函數時，用它們檢查輸入、提醒使用者：

R
safe_mean <- function(x) {
  if (!is.numeric(x)) stop("x must be a numeric vector")
  if (any(is.na(x))) {
    warning("x contains NA; they are removed")
    x <- x[!is.na(x)]
  }
  if (length(x) < 3) message("Note: fewer than 3 values")
  mean(x)
}
safe_mean(c(4, 6, NA))

## Warning in safe_mean(c(4, 6, NA)): x contains NA; they are removed
## Note: fewer than 3 values
## [1] 5
R
safe_mean(c("a", "b"))

## Error in safe_mean(c("a", "b")): x must be a numeric vector
  • 第一次呼叫：有 NA，發出警告但繼續；只剩 2 個值，再印一個提示；最後仍回傳平均數 5。
  • 第二次呼叫：輸入是文字，stop() 直接結束，不會回傳任何結果。
  • any(is.na(x))：只要有一個 NA 就是 TRUE。
重點怎麼選

要給使用者「看結果」用 print()／cat()；只是告知進度用 message()；結果可能有問題但還能用就 warning()；再算下去一定錯就 stop()。在 R Markdown 或套件裡，message 可以被 suppressMessages() 關掉，cat 不行——這也是提示性文字建議用 message 的原因。

Q4

選擇｜中警告之後

What happens when the following function is called with check(-5)?

R
check <- function(x) {
  if (x < 0) warning("negative value")
  sqrt(abs(x))
}
  1. (A)It shows a warning and returns about 2.236
  2. (B)It stops with an error and returns nothing
  3. (C)It returns NaN without showing any message
  4. (D)It returns -5 and then shows a warning

中文題意

呼叫 check(-5) 會發生什麼？

答案 (A)

It shows a warning and returns about 2.236

解析

warning() 不會停止函數，所以程式繼續執行 sqrt(abs(-5))，回傳 √5 ≈ 2.236，並在之後顯示警告訊息。如果改成 stop()，就不會有回傳值。

Q5

寫程式｜中檢查輸入的函數

Write a function discount(price, rate = 0.1) that returns the discounted price price * (1 - rate). It should stop with an error if rate is not between 0 and 1, and print a message with cat() showing the final price.

中文題意

discount <- function(price, rate = 0.1) {

  cat("Final price:", final, "\n")
  return(final)
}

條件判斷的基礎是布林值 TRUE / FALSE。

比較運算子：<、>、<=、>=、==（等於）、!=（不等於）。

& 與 &&、| 與 ||

「且」和「或」各有兩種寫法：

bmi_status <- function(height, weight) {

}

  • break：整個跳出迴圈。
  • next：跳過這一輪剩下的程式，直接進入下一輪。
  • repeat { }：無條件一直重複，必須靠 break 跳出。
R

## [1] 2
## [1] 3
R
for (i in 1:6) {
  if (i == 3) next      # i 是 3 時跳過
  print(i)
}

## [1] 1
## [1] 2
## [1] 4
## [1] 5
## [1] 6

同一個問題（計算 \(n!\)）用三種迴圈寫：

R
factorial.for <- function(n) {
  f <- 1
  for (i in 1:n) f <- f * i
  f
}
factorial.while <- function(n) {
  f <- 1; t <- n
  while (t > 1) { f <- f * t; t <- t - 1 }
  f
}
factorial.repeat <- function(n) {
  f <- 1; t <- n
  repeat {
    if (t < 2) break
    f <- f * t; t <- t - 1
  }
  f
}
c(factorial.for(5), factorial.while(5), factorial.repeat(5), factorial(5))

## [1] 120 120 120 120

大括號裡只有一行時可以省略大括號，例如 for (i in 1:n) f <- f * i。

Q4

寫程式｜難模擬機率

Write a function one() that draws 5 cards from a 52-card deck (13 cards each of h, d, c, s) and returns TRUE if the number of hearts equals the number of diamonds. Use replicate() to estimate the probability with 10,000 simulations, and compare it with the theoretical value.

中文題意

寫 one() 模擬抽 5 張牌，紅心數等於方塊數時回傳 TRUE；用 replicate() 模擬一萬次估計機率，並和理論值比較。

答案
R
one <- function() {
  deck <- c(rep("h", 13), rep("d", 13), rep("c", 13), rep("s", 13))
  hand <- sample(deck, size = 5)
  sum(hand == "h") == sum(hand == "d")
}
set.seed(2026)
mean(replicate(10000, one()))

## [1] 0.2541
R
num <- choose(26, 5) + choose(13, 1) * choose(13, 1) * choose(26, 3) +
       choose(13, 2) * choose(13, 2) * choose(26, 1)
num / choose(52, 5)

## [1] 0.2552

解析

老師的課堂練習。sample() 預設不放回，正好模擬抽牌。TRUE 當 1、FALSE 當 0，所以 mean() 就是成功比例。理論值分三種情況：紅心方塊都 0 張（5 張全從另外 26 張抽）、各 1 張、各 2 張，choose(n, k) 是組合數 \(C^n_k\)。模擬值和理論值（約 0.2735）很接近，代表模擬寫對了。

3.8本章小結

  • 函數：名稱 <- function(引數 = 預設值) { ... }；最後一行自動回傳，return() 可提早結束；回傳多個結果用 list。
  • 輸出：print() 印物件、cat() 格式化輸出（搭配 \n 換行、\t Tab）、message() 提示、warning() 警告但繼續、stop() 錯誤並停止。
  • 邏輯：== 比較、= 指派；&／| 逐元素、&&／|| 單一值（用在 if）。
  • 判斷：if 處理單一條件、ifelse() 處理向量、switch() 多分支。
  • 迴圈：for 已知次數、while 直到條件不成立、repeat + break；next 跳過這一輪。
  • apply 家族：apply() 列／行、lapply() 回 list、sapply() 簡化、tapply() 分組、replicate() 模擬、do.call() 展開 list。
